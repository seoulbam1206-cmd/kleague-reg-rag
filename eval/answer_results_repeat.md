## Q32 (1/3회). 구급차 2대가 필요하다는데, 경기 중 1명이 부상당해 1대가 병원으로 가면 대체 구급차가 올 때까지 대기해야 해?

- 확인 목적: 상황 적용: 직접 규정이 없을 때 찾을 수 없음으로 답하고, 화면 참고 목록에 관련 조항이 나오는지
- 정답 요지: 규정에서 찾을 수 없다. 화면 참고 목록에 경기 규정 제6조(특수구급차 1대 포함 최소 2대 이상 대기)가 포함된다.
- 찾을 수 없음 처리: 예

```
규정에서 찾을 수 없습니다.
```

- 찾을 수 없음 사유: LLM이 찾을 수 없다고 답함
- 화면 참고 목록: 경기 규정 제6조 의료시설 / K리그 안전 가이드라인 제16조 의료 ①~② / K리그 경기장 시설기준 가이드라인 별첨1 경기장 시설기준 일람표
- LLM 원문:

```
규정에서 찾을 수 없습니다.
```

```
근거
[1] 경기 규정 제6조 의료시설 (7쪽, 기준일 2026-06-17)
[2] K리그 안전 가이드라인 제16조 의료 ①~② (23, 24쪽, 기준일 2026-06-29)
```
